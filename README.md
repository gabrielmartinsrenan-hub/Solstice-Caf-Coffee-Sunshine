# ☀ Solstice Café — Coffee Shop Website

A fresh, editorial-style coffee shop landing page built with **HTML5, CSS3, and vanilla JavaScript**. Designed as a front-end portfolio project, with a warm peach-and-sage palette, elegant serif typography, curved image cards, and a welcoming café aesthetic.

## Features

- Fully responsive layout for desktop, tablet, and mobile
- Mobile navigation with accessible expanded state
- Interactive menu filters (All favorites, Coffee, Bites & pastries)
- Hero, Our Story, Menu, Moments, Visit, and Footer sections
- Semantic HTML and descriptive image alt text
- No frameworks, build tools, or dependencies required

## Run locally

1. Download or clone the repository.
2. Open `index.html` in a browser, or use **Live Server** in VS Code.

## Project structure

```text
solstice-cafe/
├── index.html
├── styles.css
├── script.js
└── README.md
```

## Publish with GitHub Pages

1. Push the files to a public GitHub repository.
2. Go to **Settings → Pages**.
3. Select **Deploy from a branch**, choose `main` and `/ (root)`, and save.
4. Open the URL GitHub provides.

## Customize

- Change colors in the CSS `:root` variables.
- Edit menu items and prices in `index.html`.
- Replace the demo address, email, and opening hours with real business information.
- Replace Unsplash image URLs with your own licensed photography.

## Image credits

Demo photos are loaded from [Unsplash](https://unsplash.com/). Images require an internet connection. Check the applicable image licensing terms before commercial use.

## Note

Solstice Café is a **fictional business** created for portfolio demonstration. Contact details, prices, and hours are placeholders. There is no online ordering or backend integration.
